# Industrial Analytics Studio

A Streamlit dashboard for **synthetically generated** factory production data. Explore daily units, rejected items, downtime, headline KPIs and exportable CSV.

## Run
```bash
pip install -r requirements.txt
streamlit run app.py
```

The demo generates reproducible sample data using a fixed random seed; it does not contain confidential industrial data. Potential extensions include SQL ingestion, forecasting, anomaly alerting and data-quality monitoring.
