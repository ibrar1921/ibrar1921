# Ibrar Pervaiz — Portfolio Website

Responsive, accessible, static personal portfolio using HTML, CSS and JavaScript, with no external dependencies.

## Preview
Open `index.html` locally in a browser, or serve the folder using:
```bash
python -m http.server 8080
```
Visit http://localhost:8080.

## Deployment
To publish on GitHub Pages, copy this site's three web files to a dedicated public repository (for example `ibrar1921.github.io`) and enable Pages in repository settings. The site is **not deployed automatically** from this subdirectory.

Project links point to source-code folders within the GitHub profile repository.
